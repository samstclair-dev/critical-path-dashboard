Predecessors: comma-separated task IDs. Add ":N" for an N work-day lag (e.g. offsite fabrication).
Durations are in working days (federal holidays + weekends auto-skipped, shown shaded above). Drag a bar/milestone left or right on the chart to reschedule it — its dependents recalculate live as you drag (press Esc to cancel a drag). A task with predecessors can't be dragged earlier than they allow; it will stop at the earliest feasible date. Your work autosaves to this browser automatically (the indicator up top shows autosave status) — closing the tab or reloading won't lose anything.
Autosave only lives in this browser on this device, though. Use Export this project for a portable backup of just what you're viewing, or Export all projects to back up your whole project list at once — either way you can carry the file to your phone, another computer, or a synced folder (Dropbox, Google Drive, OneDrive, iCloud Drive). Since each carries a fixed filename, re-exporting after edits overwrites the same file rather than piling up copies (if your browser asks where to save, just choose "Replace"). Use Import JSON to load a schedule file — it's always added as a new project in the dropdown above, so your existing projects are never overwritten. On the Subcontractors tab, Import subs from file instead pulls contact info into the project you're currently viewing without touching its tasks — it only fills in fields that are still blank.
